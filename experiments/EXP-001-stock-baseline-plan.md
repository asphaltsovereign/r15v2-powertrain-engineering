# EXP-001 — Stock baseline evidence plan

**Status: NOT RUN.** This document is a proposed procedure, not a completed test report.

Objective: record repeatable stock-fuel stationary behavior after vehicle-condition and measurement-interface review. Keep control hardware and calibration unchanged.

Before testing: qualified supervisor confirms vehicle mechanical condition and a suitable ventilated test location; record actual revision/maintenance state privately; verify protected interfaces and instrument calibration; complete the independent logger's USB-bench gate; define stop criteria and a safe measurement plan.

For each permitted operating condition record start/end, ambient conditions, instrument IDs, raw session hash, time basis, channel units, health flags and repeatability. A probe temperature is named by where/how it is attached. Do not infer combustion temperature, lambda or fuel composition from unrelated channels.

Acceptance evidence: original files, calibration/reference comparisons, repeated-condition plots, a missing-data/sequence report, and a conclusion limited to measured signals. Vehicle registration, GPS traces and operator contact information do not belong in the public example.

Results: none. No date, pass mark, measured value or improvement is entered until the run is performed.
